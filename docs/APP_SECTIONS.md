# App sections

## Bookmarks modal

Saved tiles show the title, optional segment, and compact Go button in the bottom-right corner with padding while collapsed. Go opens the saved location; tapping the rest of the tile expands the Wolo Code and street address. The three-dot menu provides Edit and Delete.

The add/edit form contains Title, Segment, Address line 1 (optional), and Address line 2 (optional). Users can provide either or both address lines, or leave both blank. Saved lines display together in the expanded tile and map Address Panel. Existing bookmarks remain editable.

Local bookmarks have an info icon beside Go. The icon opens storage information and a Sync to cloud button. Sync is dimmed while signed out and opens sign-in when clicked; while signed in, it saves the bookmark to the cloud before removing the local copy.

Guide captions: the decode scanner and its parent stay above the guide overlay. Scan and Saved captions appear above their decode buttons; the map Saved caption appears below its bookmark button. Previous stays enabled during the guide even when city history is empty; its normal availability returns after dismissal. Static copyright footer text hides the browser caret without affecting input cursors.

In light mode, the Map View scanner icon uses the same higher-contrast gray (#777) as the search icon. The color applies to its artwork only.
